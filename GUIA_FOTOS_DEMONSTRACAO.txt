GUIA DE FOTOS DEMONSTRATIVAS — PLOUTY
=====================================

Pasta principal
---------------
Coloque todas as imagens dentro de:

public/images/social/

As subpastas já esperadas pelo projeto são:

public/images/social/avatars/
public/images/social/covers/
public/images/social/posts/

Use exatamente os nomes abaixo. Ao adicionar um arquivo com o nome correto, a
foto aparece automaticamente na interface, sem precisar alterar componentes.


1. Fotos quadradas de pessoas e instituições
---------------------------------------------
Formato recomendado: JPG, perfil de cor sRGB.
Dimensão recomendada: 600 x 600 px ou maior, sempre quadrada (proporção 1:1).
O conteúdo central deve ter uma margem segura porque algumas fotos aparecem
recortadas em círculo.

2. Capas do resumo do usuário
-----------------------------
Formato recomendado: JPG, perfil de cor sRGB.
Dimensão recomendada: 1200 x 375 px (proporção aproximada de 16:5).
Evite texto importante nas bordas porque a imagem usa object-fit: cover.

Pasta: public/images/social/covers/

3. Imagens principais dos posts
-------------------------------
Formato recomendado: JPG, perfil de cor sRGB.
Dimensão recomendada: 1600 x 900 px (proporção 16:9).
O feed aplica object-fit: cover e mantém a proporção em desktop e celular.

Como substituir uma imagem
--------------------------
1. Prepare a foto na proporção recomendada.
2. Renomeie o arquivo exatamente como indicado neste guia.
3. Copie para a subpasta correspondente.
4. Atualize a página no navegador. Não é necessário alterar o código.

Para trocar uma foto existente, substitua o arquivo mantendo o mesmo nome.


Como adicionar uma nova imagem a um novo mock
---------------------------------------------
1. Coloque o arquivo na subpasta adequada, usando um nome curto e descritivo.
2. Em src/data/socialFeedData.js, use “avatar” para foto de autor ou comentário
   e “postImage.src” para a imagem principal do post.
3. Em src/data/socialSidebarData.js, use “avatar” para novas sugestões.
4. Em src/data/dashboardData.js, use “avatar” e “coverImage” para novos usuários
   demonstrativos.
5. O caminho público sempre começa por /images/social/. Exemplo:
   /images/social/avatars/nome-da-pessoa.jpg


Quando um arquivo não existe
----------------------------
Fotos de pessoas e instituições são substituídas automaticamente pelas iniciais.
Capas recebem uma composição visual da própria Plouty.
Posts exibem um placeholder com o nome do registro esperado.
Nenhum componente mostra o ícone de imagem quebrada.

As imagens permanecem locais: o projeto não envia arquivos para servidor.
