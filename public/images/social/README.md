# Imagens do feed social

As fotos demonstrativas são organizadas nas subpastas `avatars/`, `covers/` e
`posts/`. Os nomes já estão configurados nos mocks: basta colocar os arquivos nos
locais indicados.

Consulte `GUIA_FOTOS_DEMONSTRACAO.txt`, na raiz do projeto, para ver a lista
completa de nomes, pessoas, instituições, dimensões e proporções recomendadas.

Quando um arquivo não existe, a interface usa iniciais ou um placeholder da Plouty
e não exibe ícones de imagem quebrada.
